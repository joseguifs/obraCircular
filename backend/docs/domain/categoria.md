# Regras de Domínio — Categoria

## Status

- `ATIVA`
- `INATIVA`

## Regras

- O nome da categoria é único.
- Apenas categorias `ATIVA` podem ser utilizadas em novos anúncios.
- Inativar uma categoria não exclui nem modifica anúncios existentes.
- A reativação permite novamente a criação de anúncios na categoria.
